# AI Projects

This repository contains four AI-based projects developed using Python and Machine Learning. Each project focuses on solving a different real-world problem using Artificial Intelligence.

## Projects

### TASK 1: Language Translation Tool
A Python-based application that translates text from one language into another using translation libraries.

### TASK 2: Chatbot for FAQs
An AI-powered chatbot that answers frequently asked questions using Natural Language Processing (NLP).

### TASK 3: Music Generation with AI
An AI-based application that generates music using deep learning and LSTM models.

### TASK 4: Object Detection & Tracking
A computer vision project that detects and tracks objects in videos using YOLO.

## Technologies Used
- Python
- Machine Learning
- Deep Learning
- Natural Language Processing (NLP)
- Streamlit
- TensorFlow
- YOLO
- OpenCV
